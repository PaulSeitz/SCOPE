```bash

export PAPER_EVAL_JAXATARI_ROOT=$JAXATARI_ROOT
```

## Locked recipe

- Outer loop: 1024 envs × 32 steps × 1525 updates (= 50,000,000 env steps), 2 epochs × 256 minibatches.
- LR 0.00025 linear decay (SKILL_LR = META_LR = LR), MAX_GRAD_NORM 10, ε 1.0→0.001 over 10% (skills + meta), γ 0.99, λ 0.65.
- Ego spine: POV facing frame, ψ 8 bins, no distance clip, no extra channels, sparse C/D/A, DESTROY contact-fail, no living penalty, surfacesub5.
- Train seeds 44, 45, 46; eval EVAL_SEED = seed + 10000, 3 eval seeds × 3 episodes per mod (floors: 9 × 3, single config).
- Seaquest mods: base, no_enemies, swap_diver_enemy_labels, swap_diver_shark_roles, gravity, faster_enemies, shift_lanes, random_spawns, change_background_color.
- namethisgame mods: base, shift_tentacle_spawn_x, slower_player, faster_shark, no_shark_short_tentacles.
- spaceinvaders mods: base, shift_shields, shift_formation, slow_tank, faster_aliens, saucer_only.
- beamrider mods: base, three_lanes, slow_strafe, double_enemy_speed, idle_at_range.
- asteroids mods: base, no_momentum, faster_asteroids, frozen_asteroids.
- pong mods: base, shift_player, linear_movement, lazy_enemy.
- breakout mods: base.
- freeway mods: base, stop_all_cars, static_cars, slow_cars, invert_speed, center_cars_on_reset, bikes.
- phoenix mods: base, formation_reshuffle, player_drift, fast_enemy_bullets, static_score_bait.
- Tandem meta OC = `oc_simple_rel_role`; flat PQN OC = `oc_simple_rel_role` (same feature builder). Skill OC ablation = `oc_flat_rel` (same relative rows + `is_target`, flattened MLP; no role-pool / set encoder).
