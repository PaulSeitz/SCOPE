# Thesis-final evaluation specification

Locked recipe for the 50 M paper-eval sweep used in the thesis
(`suite:thesis_final`). Source of truth for generation:
`scripts/materialize_thesis_final.py`. Autogenerated per-run schedule:
`docs/thesis_final_RUNLOG.md`. Cluster launch (2026-10-09): tmux
`PS_CBL_full`, GPUs 0–2, W&B project `concept_based_learning`.

Do not edit the YAMLs under `configs/experiment/paper_eval/thesis_final/`
by hand — re-run the materializer.

---

## Seeds

### Training (every learned arm)

| | |
|---|---|
| Train seeds | **44, 45, 46** (three independent runs) |
| Config layout | one YAML per seed (`NUM_SEEDS: 1`, top-level `SEED`) |
| Applies to | skills, flat PQN (pixel / OC), tandem, NEXUS symbolic, home HRL |

There is no multi-seed loop inside a single train config.

### Evaluation (checkpoint / policy rollout)

For a checkpoint trained with seed \(s\):

| | |
|---|---|
| Base eval seed | `EVAL_SEED = s + 10_000` (so 10044 / 10045 / 10046) |
| Eval seed count | **`EVAL_NUM_SEEDS = 3`** → seeds `EVAL_SEED`, `+1`, `+2` |
| Episodes per (mod × eval seed) | **3** (`--eval-episodes 3` / runner default) |
| Episodes per mod (normal arm) | \(3 \times 3 = 9\) |
| Episodes per mod across 3 train seeds | \(3 \times 9 = 27\) |

Eval seeds are intentionally disjoint from train seeds (no
`EVAL_SEED == SEED`).

### Attribution floors (eval-only, no train seed)

| | |
|---|---|
| Anchor | `SEED = 44`, `EVAL_SEED = 10044` |
| Eval seed count | **`EVAL_NUM_SEEDS = 9`** |
| Episodes per (mod × eval seed) | 3 |
| Episodes per mod | \(9 \times 3 = 27\) |

Floors use 9 eval seeds × 3 episodes so the episode budget matches
“3 train seeds × 3 eval seeds × 3 episodes” of a learned arm, without
training three floor policies.

### Quick reference

| Role | Count | IDs / formula |
|------|------:|---------------|
| Train seeds (learned arms) | 3 | 44, 45, 46 |
| Eval seeds per ckpt | 3 | \(s+10000 \ldots s+10002\) |
| Episodes / eval seed / mod | 3 | runner default |
| Floor eval seeds | 9 | 10044…10052 |
| NEXUS train seeds | 3 | 44, 45, 46 (same as above) |
| NEXUS mod-eval | 3 seeds × 3 eps | `--seed s+10000 --eval-num-seeds 3` |

## Outer-loop HPs (all learned CBL arms)

PQN optimal-scaling 1:1 — shared by skills, meta, and flat PQN heads:

| Knob | Value |
|------|------:|
| Env steps | 50 000 000 |
| `NUM_ENVS` × `NUM_STEPS` × updates | 1024 × 32 × 1525 |
| Epochs × minibatches | 2 × 256 |
| LR (`LR` = `SKILL_LR` = `META_LR`) | \(2.5\times10^{-4}\), linear decay |
| `MAX_GRAD_NORM` | 10 |
| ε | 1.0 → 0.001 over 10% of decay horizon |
| γ / λ | 0.99 / 0.65 |
| Frame skip / stack | 4 / 4 |
| Off-policy PQN | on (`OFF_POLICY: true`) |
| Reward clip / first-fire / episodic life | on / on / on |

## Ego / observation spine (skills + tandem skills)

Locked “minimal facing” ego:

- POV relative mapper + **facing frame**; ψ **8** bins
- No distance clip (`EGO_DISTANCE_CLIP_MAX_PX: null`)
- Extra channels off: size, velocity, blocking, weapon, facing-enemy, shot
- Sparse COLLECT / DESTROY / AVOID; DESTROY contact-fail; no DESTROY living tax
- Seaquest surface-sub near range **5** (surfacesub5 labeling)

Ablations (Seaquest only, still ×3 seeds):

- `skills_pixel_outline` — pixel skills with target outline
- `skills_nopov` — world-frame θ 8 bins, no POV facing
- `skills_oc_flat_rel` — flattened player-relative object list + `is_target`
  (same relative row schema as meta/PQN `oc_simple_rel_role`, but flat MLP;
  no role-pool / set encoder)

**Not run:** skill `oc_embed`. Flat PQN OC and tandem meta OC both use
`oc_simple_rel_role` only.

## Arms and environments

### Home envs (RQ1 / RQ3 core)

`seaquest`, `timepilot`, `namethisgame` — each × seeds 44/45/46:

- `skills_ego` (+ home mod eval)
- `pqn_pixel`, `pqn_oc` (+ home mod eval)
- `tandem_oc` (+ home mod eval); Seaquest also `tandem_pixel`

### Seaquest → transfer targets (RQ2 core)

Zero-shot: Seaquest `skills_ego` ckpt + **target** heuristic, for each of
the 9 non-Seaquest envs × 3 seeds.

### Extras

- Native `skills_ego` ceilings on the 7 non-home transfer targets × 3 seeds
- In-family ZS: timepilot→asteroids, namethisgame→spaceinvaders × 3 seeds
- Tandem-skill ZS: Seaquest `tandem_oc` skills → timepilot / namethisgame × 3 seeds

### Floors (eval only)

On every env: `random_actions`, `heuristic_random`, `fixed_ego_rules`.  
On home envs additionally: `constant_ego`.

### NEXUS / HRL (outside `run_paper_eval`)

Seeds 44/45/46; mod-eval uses `EVAL_SEED = s+10000`, 3 eval seeds × 3 episodes.

**Symbolic NEXUS** (Seaquest only, author paper HPs):

- `cbl_seaquest_nexus_symbolic_paper` + Seaquest thesis mod strip

**HRL / HPQN baseline** (all three home envs, CBL 50M optim 1:1,
`NO_REWARDS`, `NUM_AGENTS=3`, learned meta):

- `cbl_seaquest_hrl_baseline_optim50m`
- `cbl_timepilot_hrl_baseline_optim50m`
- `cbl_namethisgame_hrl_baseline_optim50m`

Each home uses that env’s thesis / `paper_core` mod strip
(`scripts/run_thesis_final_nexus.sh`). Legacy
`cbl_seaquest_hrl_baseline_paper` (NEXUS paper outer HPs) is kept on disk
but is not part of the thesis_final schedule.

## Reporting convention (thesis)

- **Train variability:** mean ± std (or min–max) over the **3 train seeds**.
- **Per-seed eval score:** mean over the **3 eval seeds × 3 episodes**
  (9 rollouts) per mod; aggregate mods as needed (base vs OOD strip).
- **Floors:** one config, mean over **9 eval seeds × 3 episodes** (27
  rollouts) so the episode count matches a 3-seed learned arm.
- W&B: project `concept_based_learning`, tags include `suite:thesis_final`,
  `rq:*`, `env:*`, `arm:*`, `budget:50m_optim`.
